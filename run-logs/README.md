# RUN LOGS

Registro humano das sessões de trabalho. Um arquivo por sessão:
`YYYY-MM-DD-<assunto>.md`.

> **Estado: vazio.** A execução não começou.

## Formato

```markdown
# YYYY-MM-DD · <assunto>

**Tickets:** DRI-###, DRI-###
**Duração:** —

## O que foi feito
## O que não funcionou
## Decisões tomadas fora do DECISION_LOG
## Para a próxima sessão
```

## O que merece registro

- Tentativa que **falhou** e por quê — vale mais que a que deu certo
- Suposição que se revelou falsa
- Tempo gasto em algo que parecia trivial

## Registro obrigatório

O **marco D+21** (apuração ensaiada verificada por terceiro) tem run log próprio e versionado. É
a evidência que sustenta a afirmação central do produto — não pode viver só num comentário do Jira.
